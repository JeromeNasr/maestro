Each classic is a *rendering of public-domain music from a typeset score*; the typesetter's licence is what is recorded. Per-piece provenance (pinned commit, source path, licence text found in the header, maintainer, every mechanical edit) is in `public/midi/classics.json`, produced by `scripts/music/build-classics.mjs`. The only changes are syntax updates needed by LilyPond 2.24, instrument names/programs, bass octave conventions, the stated bass doublings and reference tempo; no note was added, removed or moved. Reference tempos are editorial (the listener sets the real tempo by conducting).

**Action for the project owner:** the three original compositions were written with AI assistance. Whether such works are copyrightable, and therefore whether a CC0 dedication is meaningful, depends on jurisdiction. Confirm the dedication (or choose another licence) before publishing. The copyright notice embedded in each file says CC0-1.0.
