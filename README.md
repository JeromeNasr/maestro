# MAESTRO — Conduct Your Own Orchestra

Browser-based virtual orchestra controlled by webcam hand tracking. Runs locally; no backend; camera frames never leave the browser.

```bash
npm install
npm run dev      # http://localhost:5173
npm test
npm run build
```

Current status and architecture: see `CLAUDE.md`. Asset licences: see `LICENSES.md`.
**Phase 1 only**: the interface exists; camera, gestures and audio are not implemented yet.
